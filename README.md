# Essandoh Prince Takyi — Portfolio

A portfolio site showcasing product design and engineering case studies.

**Built with:** React 19 + TypeScript + Vite + Tailwind CSS

## Projects featured

- **Shuttle App** — Real-time shuttle tracking for Ghanaian universities (KNUST, UG, UCC)
- **Gas App** — LPG cylinder booking and delivery tracking
- **Vendor Pro** — Vendor and order management dashboard
- **Uzeka** — Multi-platform event ticketing ecosystem
- **Gas Volume Sensor** — IoT gas consumption monitoring

## Running locally

```bash
npm install
npm run dev
```

## Deploy

Hosted on Vercel. Push to `main` to trigger a deployment.
